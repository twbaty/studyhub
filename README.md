# StudyHub

> Learn First. Test Later.

StudyHub is a lightweight, portable learning platform for creating interactive study guides.

Unlike traditional flashcard applications, StudyHub emphasizes understanding through explanations and guided review before measuring retention through testing.

The goal is simple:

> Build knowledge, not just scores.

---

## Why StudyHub?

Many study tools focus almost entirely on memorization or exam simulation.

StudyHub is designed around a different philosophy:

- Learn concepts first
- Review interactively
- Test only after understanding

The platform separates educational content from the application itself, allowing new subjects to be added without changing the software.

- Structured notes
- Markdown documentation

- Images and diagrams

- Interactive multiple-choice questions
- Immediate feedback
- Detailed explanations

### Review Mode

- Review missed questions

- Adaptive repetition
- Browse by category

### Practice Mode

- Timed practice exams
- Randomized questions
- Score reports
- Missed question review

### Content

- Portable Markdown
- JSON question banks

- PDFs

## Project Philosophy

StudyHub follows several guiding principles.

- Learn before testing.
- Explanations are more valuable than scores.
- Knowledge should remain portable.
- Content should be independent of software.
- Learning should work offline whenever possible.

- Vision.md
- Philosophy.md
