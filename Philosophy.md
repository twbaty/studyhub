# StudyHub Philosophy

## Learn First

Testing measures knowledge.

Learning creates knowledge.

StudyHub prioritizes learning.

The default experience should always help users understand *why* something is
correct before asking them to remember it.

---

## Build While Learning

Every study guide represents research performed during the learning process.

Instead of hiding that journey, StudyHub documents it.

The result is a growing collection of structured knowledge that benefits both
its author and anyone else who wishes to use it.

---

## Explanation Over Memorization

Questions are only valuable when accompanied by meaningful explanations.

Every answer should teach.

---

## Portable Knowledge

Knowledge should survive technology.

Content should be stored using open formats whenever practical.

Preferred formats include:

- Markdown
- JSON
- PNG
- SVG
- PDF
- CSV

The application should never lock educational content into proprietary storage.

---

## Separate Content from Software

The software is a presentation engine.

The content is independent.

The application should not know anything about CHFI, ACTAR, CEDS, or any other
subject.

It simply presents whatever content has been provided.

---

## Local First

Learning should not require an Internet connection.

Whenever possible:

- Progress remains local.
- Notes remain local.
- Study guides remain portable.

Cloud synchronization may exist someday, but it is never required.

---

## Open Learning

StudyHub is provided freely.

Use it.

Modify it.

Share it.

Verify everything.

No guarantee is made regarding correctness or certification readiness.
